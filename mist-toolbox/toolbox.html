Authoring guide

Choose a tool's .js file. It is checked first, then written into this extension's tools/ folder and listed in tools/tools.json. The first install in a tab asks you to pick the extension's folder (the one you chose with Load unpacked). Have a Python or Node script instead? Use Copy AI prompt to convert it. Tools that make changes to Mist are allowed, but they get a strong warning here, a Makes changes label and a confirmation before they run. Read-only tools are best practice.
